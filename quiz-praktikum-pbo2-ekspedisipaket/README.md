# Sistem Ekspedisi Paket

## Penjelasan Sistem

Sistem ekspedisi paket digunakan untuk membantu proses pengiriman barang. Secara umum, sistem ini mencatat data pengirim dan penerima, informasi paket, serta layanan pengiriman yang dipilih. Sistem kemudian dapat menghitung biaya pengiriman berdasarkan aturan yang berlaku dan menampilkan ringkasan atau status pengiriman.

Alur umumnya dimulai dari memasukkan data pengiriman, memilih jenis layanan, menghitung biaya, lalu menyimpan atau menampilkan informasi transaksi. Detail fitur dan aturan perhitungan mengikuti implementasi program.

## Konsep yang Terlibat

- **Pemrograman Berorientasi Objek (PBO):** memodelkan entitas seperti paket, pelanggan, dan layanan sebagai objek.
- **Class dan object:** class menjadi cetak biru, sedangkan object menyimpan data konkret untuk setiap transaksi atau entitas.
- **Atribut dan method:** atribut menyimpan informasi, sementara method menjalankan proses seperti menghitung ongkir atau menampilkan detail paket.
- **Enkapsulasi:** mengelompokkan data dan perilaku dalam class serta mengatur akses terhadap data.
- **Konstruktor:** menginisialisasi object dengan nilai awal, misalnya data pengirim, tujuan, dan berat paket.
- **Percabangan dan perulangan:** mendukung pemilihan layanan, validasi input, dan pengulangan menu apabila digunakan.
- **Tipe data dan input/output:** mengelola informasi seperti nama, alamat, berat, tarif, serta menampilkan hasil kepada pengguna.
- **Validasi dan perhitungan:** memastikan masukan sesuai kebutuhan dan menghitung biaya berdasarkan ketentuan program.

Konsep pewarisan, polimorfisme, atau penyimpanan data dapat diterapkan jika struktur dan kebutuhan program menggunakannya.
